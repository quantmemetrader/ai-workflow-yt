# 亚芳·创变派 工作台 · Aura Video Workspace

从选题到成片，一个工作台：**选题研究 → 剧本 → 剪辑（一键成片）→ 导出**，中间的每一步都可以用一句话让助理去做。

From topic to finished video in one place: **Research → Script → Video (one-brief director) → Export**, with an assistant at every step that edits by prompt.
