# 选题研究 · Research

**看板 · Trends board.** 左边是频道记忆（你自己频道的 122 条视频与「创作者声音」笔记，进入每一次模型调用），中间是当前选题的热度曲线、来源、建议角度和决定卡，右边是关注列表。

**关注一个选题 · Watch a topic.** 在「搜索或关注一个选题…」里输入一个短语，回车。工作进程会去抓来源（新闻、GDELT、Hacker News、YouTube 等），几十秒后卡片有了热度和来源；每天再刷新。

**决定 · Decide.** 每个选题有三个决定：「写剧本 →」直接把它写成剧本；「采纳 → 待办」进入选题待办的看板；「拒绝」告诉排序它不合口味（排序权重会学）。

**角度 · Angles.** 「建议角度」让助理从已读来源里给出三个切入角度；写剧本时选一个。

**其它页面 · Other screens.** 搜索与对比（多个选题的曲线叠在一起）、内容表现（自己频道每条视频的日观看、完播）、评论收件箱（回复草稿、隐藏、分类）、选题待办（看板：采纳 → 写简报 → 写剧本 → 交付）。

**助理 · Assistant.** 右下角。它能：列出关注的选题、读来源、建议角度、写剧本、查频道的视频。历史记录与「新对话」在输入框上方。
