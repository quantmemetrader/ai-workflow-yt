# 剪辑 · Video

**项目 · Projects.** 「项目」页签是所有剪辑的卡片：缩略图、时长、片段数、是否已渲染、最近编辑时间；可排序、重命名、删除。「新建项目」建一个空项目；从剧本来的项目已经关联剧本。

**素材 · Footage.** 在时间线「画面」轨旁按 **+**，或把文件拖进来：文件直传对象存储（R2），落在素材栏与时间线上，缩略图与时长几秒内出现。也可以从文件库里「添加」已有的视频，或让导演从素材库（Pexels / Unsplash / Openverse）自己找。

**一键成片 · The director.** 顶部的条：写一句话说清想要的片子（主题、平台、情绪、要留要去、谁的名字上），选画幅（16:9 / 9:16 / 1:1）与节奏：

- **克制 Calm** — 一镜一意，留白。
- **频道 Channel** — 频道自己的节奏：片头题、水印脚注、双语字幕高亮关键词、每个提到的东西配图、**空镜时人像留在右上角的圆形画中画**（从创作者成片量出来的版式）。
- **炸裂 Hype** — 每提到的东西都满屏上图，每 2 到 4 秒一个。

勾选「完成后直接渲染成片」，按「开始制作」。步骤条显示：读素材 → 转写（带词级时间）→ 剪（去停顿、选段）→ 设计（标题、字幕、推近、空镜、配图，一次模型调用，写回时间线）→ 渲染。离开页面也没关系：右上角有渲染中的提示，完成后有通知。工作进程重启也不怕：任务自动回队列并从渲染一步接着做。

**时间线 · Timeline.** 画面 / 字幕 / 图形 / 音频四条轨。拖动块移动，拉边缘修剪，双击拆分；右侧检查器改入场动画（淡入、上升、弹出、滑入、落下、推进、砸入）、位置（含 `pip`）、缩放、推近倍率。

**图形 · Graphics.** 片头题、水印、脚注、论断块（用【】标关键词，用 | 分行）、大数字、卡片、姓名条、图标、图片（满屏或角落）、空镜（满屏 / 画中画 / 角落）、推近。图形由 Remotion 绘制成静帧，缓存按内容命中，再次渲染不重画。

**字幕 · Captions.** 转写后自动有；双语预设：中文粗体 + 关键词强调色 + 小号英文；也有清爽、口播、弹出、播报、论断等预设。可以逐条改时间和文字。

**按提示修改 · Edit by prompt.** 右下角助理：「把片头题改短」「第 15 秒加一个推近」「把这句做成大数字」「找一段海军的空镜放在 40 秒」……它调用工具改时间线，改完刷新。历史记录与「新对话」在输入框上方。
