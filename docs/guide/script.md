# 剧本 · Script

**从选题来 · From a topic.** 在选题卡上点「写剧本 →」，表单里选角度、时长、语言，点「开始写」。剧本用你频道的口吻写（创作者声音笔记在提示里），逐段带画面说明与口播，字数按目标时长算；短了会自动扩写一轮。

**剧本库 · Library.** 文件夹、草稿/简报分组、搜索；点卡片或列表行的任何位置打开。

**详情 · Detail.** 简报 / 草稿 / 版本 / 审批四个页签；右侧是房屋风格检查（是否符合频道规范）、助理、评论。「保存一个版本」记录版本；「发送审批」走审批；锁定只能由非作者批准。

**去剪辑 · Make the video →.** 详情页右上角。它会新建一个剪辑项目并把剧本关联上，直接落在剪辑页的「剪辑」页签。
