# 导出与文件 · Export & Files

**导出 · Export.** 「导出」页签：选画幅、是否烧录字幕、字幕语言，「开始渲染」。进度来自编码器本身；完成后一行「已渲染」，点开就是文件。离开页面会有渲染中的提示与完成通知。

**渲染怎么做 · How a render is made.** 一次 FFmpeg：按片段修剪、拼接（含转场）、推近、空镜（满屏或画中画圆形）、图形静帧叠加（各自的入场动画）、字幕（libass 烧录）、响度归一（约 -16 LUFS），成片写回文件库并生成缩略图。

**文件 · Files.** 根目录是你的文件（素材库的授权图片与空镜在独立文件夹「素材库 · Stock」里，全工作室可见）；最近、共享、回收站；网格 / 列表 / 画廊；缩略图会等到生成为止；文件详情页可播放、下载、分享（链接与权限）。
