# 助理 · Assistant

每个模块的右下角都有助理，用同一套工具包，按模块开放：

| 模块 | 它能做的事 |
| --- | --- |
| 选题研究 | 列关注选题、读来源、建议角度、写剧本、查自己频道的视频与表现 |
| 剧本 | 改写选段、按频道规范检查、扩写/缩写、把剧本变成剪辑项目 |
| 剪辑 | 一键成片（可指定节奏）、列素材、加片段、加图形、推近、加空镜（画中画）、改入场、改外观、找素材库图片与空镜、导出 |
| 聊天 | 读频道消息、总结、@提及 |

每条工具调用都以小标签显示在回答里；「历史」打开以前的对话，「新对话」重来。模型在输入框下方可切（默认 deepseek-chat；管理员可在设置里改默认与预算）。
